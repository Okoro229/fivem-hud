Ce qui est toujours inclus

  • Code source complet, non obfusqué.
  • Installation : je vous guide pas à pas, ou je le fais si vous me donnez un accès.
  • 30 jours de corrections après livraison, sans frais.
  • Documentation en français : commandes, permissions, configuration.

Ce qui n'est pas inclus

  • L'hébergement du serveur.
  • Les ressources tierces (framework, inventaire, etc.).
  • Les modifications demandées après validation du cahier des charges : elles font

l'objet d'un nouveau devis.

Délais et paiement

  • Délai : compté à partir de la validation du cahier des charges, pas de la

première conversation.

  • Paiement : 50 % à la commande, 50 % à la livraison. Pour un premier projet

sous 100 €, paiement intégral à la livraison.

  • Moyens : virement, PayPal, ou crypto sur demande.

L'audit est gratuit si vous commandez ensuite un script. Il est facturé si

vous ne commandez rien — c'est ce qui permet de le proposer sans le brader.

Pour commander

Décrivez ce qu'il vous manque en trois phrases : le framework (QBCore, Qbox,

ESX), ce que le script doit faire, et ce que vous avez déjà essayé. Je réponds

avec un prix ferme et une date.

Pas de devis « à partir de ». Pas de supplément découvert en cours de route.
